# Foodie

An Android app for discovering Michelin Guide restaurants and keeping track of the ones you want to try or have visited.

## Features

- Find restaurants within 30 km of your GPS location
- Search any city or place
- List and map views for browsing results
- Filter for stars and Bib Gourmand, plus a cuisine picker
- Restaurant details: award, cuisine, price, description, facilities and services, address and opening hours, with one-tap call and direction
- Favourites and Visited lists, with notes on places you've been
- Backup and restore of your favourites and visited places to a JSON file
- Works offline once the catalogue is downloaded
